# Fixture installation

`oer-tool-lab-fixture-install` holds the privileged programs of the Linux
fixture software: `open-radio-fixture-install`, the fixed launchers
(`open-radio-net-launcher`, `open-radio-probe-launcher`,
`open-radio-bluetooth-launcher`) and `open-radio-net-client`. It has no
library; the contract, the planning and the root apply logic are
[`oer-lab-fixture`](../fixture/README.md).
